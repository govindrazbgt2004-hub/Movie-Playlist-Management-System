
# CineQueue — Movie Playlist Management System

An MCA Data Structures and Algorithms practical project
built while learning web development.

## Technology Stack
- HTML
- CSS
- JavaScript
- Browser Local Storage
- Git and GitHub

## Features
- Movie catalogue with posters
- Add custom movies
- Playlist management using a custom Linked List
- Undo functionality using Stack
- Upcoming movie queue using FIFO
- Binary Search Tree and traversals
- Movie Graph with BFS and DFS
- Linear Search and Binary Search
- Merge Sort and Quick Sort
- Greedy Movie Marathon Planner
- Local Storage for saved movie data

## How to Run
1. Open the project folder.
2. Open index.html in a browser.
3. For local development, a VS Code Live Server extension can also be used.

## Project Purpose
To learn web development by implementing Data Structures
and Algorithms in a practical movie playlist application.
